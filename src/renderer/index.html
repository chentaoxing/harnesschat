⚠️ 使用前必读 / Please read first

HarnessChat 会在群工作区目录里以命令行方式运行各 AI harness（如 Codex、Claude Code、Qoder CLI）。根据你给每个成员选择的权限模式，它们可能无需确认即读写文件、执行命令。请只把信任的 harness 拉进群，并把工作区设为专用目录。

HarnessChat runs AI harnesses (Codex, Claude Code, Qoder CLI…) as command-line processes inside the group workspace directory. Depending on the permission mode you pick per member, they may read/write files and run commands without confirmation. Only add harnesses you trust, and point the workspace at a dedicated directory.
